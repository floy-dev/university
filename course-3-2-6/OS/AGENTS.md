# Операционные системы

## Методические материалы

- Основной источник требований для лабораторных по ОС — `docs/OS_metod.pdf`.
  Перед реализацией задания прочитать относящиеся к нему страницы методички.
- Номер варианта студента — 8. Для лабораторной работы №1 использовать:
  формат даты `d/M/yyyy`, формат времени `H:m:s`; указанные для варианта
  метрики — `SM_CXDOUBLECLK`, `SM_CYDOUBLECLK`, `SM_CXMIN`, `SM_CYMIN`,
  `SM_REMOTECONTROL`; параметры — `SPI_GETFLATMENU`, `SPI_GETKEYBOARDSPEED`.

## Лабораторная работа №1

- Функции статической библиотеки должны располагаться в `lab1/StaticLib`.
- DLL с неявным подключением должна располагаться в `lab1/ImplicitDll` и
  экспортировать объявленные в её заголовочном файле функции.
- DLL со значениями системных метрик должна располагаться в
  `lab1/ObviousDll`. Подключать её к `ConsoleApp` явно: через `LoadLibrary`,
  `GetProcAddress` и `FreeLibrary`, без `ProjectReference` и импорта `.lib`.
- DLL системных параметров должна располагаться в `lab1/DeferredDll`.
  Подключать её с отложенной загрузкой: добавить `DeferredDll.dll` в
  `DelayLoadDLLs`, включить `SupportUnloadOfDelayLoadedDLL` и вызывать
  `__FUnloadDelayLoadedDLL2` после использования.
- Пути системных каталогов получать с помощью `SHGetFolderPath` и значений
  CSIDL из таблицы 1.9 методички; не заменять их устаревшими `Get*Directory`.
- Дату и время получать через `GetLocalTime`. Для форматирования даты и
  времени использовать `GetDateFormat` и `GetTimeFormat` с форматом варианта.
- Для получения фактической версии Windows использовать `RtlGetVersion` из
  `ntdll.dll`; не применять устаревший `GetVersionEx`.
