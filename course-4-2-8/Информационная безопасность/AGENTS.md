# Информационная безопасность - правила оформления отчётов

Эти правила дополняют общие инструкции университетского архива и применяются
только к работам по дисциплине «Информационная безопасность».

## Отчёты по лабораторным работам

- При запросе на создание или обновление отчёта использовать навык
  `artifact-template-study-report` вместе с правилами работы с DOCX.
- Создавать отчёт в каталоге `labN/docs`. Не перезаписывать существующий
  отчёт без прямого указания пользователя: следующую версию сохранять с
  суффиксом `_v2`, `_v3` и далее.

## Последовательность материалов в ходе работы

Для каждого содержательного алгоритма шифрования или криптоанализа соблюдать
следующий порядок:

1. Описание реализованного участка кода и отдельный рисунок с его фрагментом.
2. Отдельный рисунок с блок-схемой этого алгоритма.
3. Отдельный рисунок с демонстрацией работы алгоритма.

- Каждый фрагмент кода, блок-схема и демонстрация оформляются как отдельный
  рисунок с последовательной нумерацией и подписью вида `Рисунок N - ...`.
- Если изображение пользователь вставит самостоятельно, размещать отдельный
  плейсхолдер под него непосредственно перед подписью рисунка.
- В описательном абзаце перед рисунком указывать ссылку `(рис. N)` без точки
  перед открывающей скобкой.
- Разделы, описывающие только интерфейс приложения или организационные
  действия, оформлять отдельными рисунками только когда это уместно для
  содержания работы.
