# Информационная безопасность

## План выполнения лабораторных работ

В рамках текущего этапа планируются лабораторные работы №1–6 из методических указаний `docs/Information_Security.pdf`. Лабораторные №7–8 в этот план не входят.

### Общие решения

- Каждая лабораторная работа оформляется как самостоятельный C# Windows Forms-проект и отдельное solution-решение в каталоге `labN`.
- Криптографические алгоритмы, требуемые методичкой, реализуются вручную. Возможности .NET допустимо использовать для `BigInteger`, криптостойкой генерации случайных чисел, файлов, кодировок и GUI.
- Все пункты методички, отмеченные `*`, включаются в работу.
- Вариант по дисциплине — 8. Для ЛР №3 это означает дополнение ISO/IEC 7816-4 и режим CFB.
- Исходную методичку и прочие материалы преподавателя не изменять.

### Состав работ

1. **ЛР №1 — классические шифры подстановки**
   - Аффинный шифр, шифр Виженера, фонетический алфавит НАТО, роторный шифр.
   - Ввод текста вручную и из файла, сохранение результата.
   - Перебор ключей для аффинного шифра; атака с известным открытым текстом на роторный шифр.

2. **ЛР №2 — классические шифры перестановки**
   - Шифры изгороди, перестановка с ключом, комбинированная и кратная перестановки.
   - Ввод текста вручную и из файла, интерактивный перебор ключей.

3. **ЛР №3 — AES**
   - Собственная реализация AES-128 для блока и массива данных.
   - ISO/IEC 7816-4, CFB, ввод ключа и IV в текстовом или шестнадцатеричном виде, поддержка файлов.

4. **ЛР №4 — простые числа**
   - Перебор делителей, решето Эратосфена, случайный общий делитель, Ферма, Рабин—Миллер и Соловей—Штрассен.
   - Генерация простых чисел заданной разрядности, включая значения больше 128 бит.

5. **ЛР №5 — Диффи—Хеллман и Эль-Гамаль**
   - Первообразные корни и безопасные простые числа.
   - Отдельные страницы интерфейса для первообразных корней, протокола Диффи—Хеллмана и схемы Эль-Гамаля.

6. **ЛР №6 — комбинированное шифрование**
   - Собственная реализация RSA и перенос автономной реализации AES.
   - Генерация ключей, шифрование данных AES, шифрование ключа RSA, обратное восстановление и сохранение промежуточных файлов.

### Проверка перед сдачей

- Проверять обратимость операций шифрования и дешифрования.
- Использовать тестовые данные из методички для AES и последующих работ.
- Проверять обработку ошибочного ввода и файлов.
- Подготавливать скриншоты интерфейса и результатов для отчёта только после фактического выполнения экспериментов.

### Предварительное требование среды

На компьютере установлена Visual Studio Community 2026 и runtime .NET 8. Перед началом реализации конкретной работы нужно удостовериться, что установлен .NET SDK или workload Windows Forms.
